# Reporting a security problem

Please report it privately: on this repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue or pull request for it.

Say what you found, which version, and how to reproduce it if you can. You will get an answer there.

The runner runs on your own computer and holds a token for one agent, so we treat anything that could let Zolaka, another program or another user of the computer make it run something else, read that token, or reach files as urgent.
